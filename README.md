# 🌍 Travel Booking Website

A professional, responsive travel booking platform built with pure HTML5 and CSS3 as part of my 2025 web development learning challenge.

## 🚀 Live Demo
[View Live Website](https://alaamohammedhanafy.github.io/travel-booking-website/)

## ✨ Features
- Fully responsive design (mobile, tablet, desktop)
- Modern UI with glassmorphism effects
- Complete booking form with validation
- Semantic HTML5 structure
- Accessible and user-friendly interface

## 🛠️ Technologies Used
- **HTML5**: Semantic markup, form elements
- **CSS3**: Flexbox, animations, gradients, media queries
- **Design**: Custom styling with modern UI/UX principles

## 📂 Project Structure
```
├── index.html          # Main HTML file
├── style.css           # Stylesheet with complete comments
└── traveling.jpg       # Background image
```

## 🎯 Form Elements Included
- Text inputs (name, email, phone)
- Radio buttons (gender selection)
- Date pickers (arrival/departure dates)
- Dropdown select (destination cities)
- Checkboxes (services selection)
- File upload (passport)
- Textarea (special requests)

## 📱 Responsive Breakpoints
- Desktop: > 768px
- Tablet: 481px - 768px
- Mobile: < 480px

## 🎨 Color Scheme
- Primary: #3498db (Blue)
- Secondary: #2c3e50 (Dark Blue-Gray)
- Accent: #e74c3c (Red for required fields)
- Background: Semi-transparent white overlay

## 🚀 Getting Started
1. Clone the repository
```bash
git clone https://github.com/AlaaMohammedHanafy/travel-booking-website.git
```
2. Open `index.html` in your browser
3. That's it! No build process required.
